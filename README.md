# Milaap — Student Innovation & Collaboration Platform

> A centralized platform designed to help students discover opportunities, participate in innovation events, build teams, submit projects, and track their skills and performance.

##  Overview

**Milaap** is a student-focused innovation and collaboration platform that brings events, team formation, project submissions, skill development, and performance tracking together in one place.

The platform is designed to simplify the student innovation journey — from discovering an event and forming a team to submitting projects and analyzing individual performance.

##  Key Features

###  Event Management

* Browse and explore upcoming innovation events and competitions
* View detailed event information
* Track event participation and progress
* Dedicated interfaces for organizers and participants

### Team Formation

* Create and manage teams
* Discover potential teammates
* Facilitate collaboration based on skills and interests

###  Student Dashboard

* Personalized student dashboard
* Track participation and achievements
* View performance-related insights
* Monitor skill development

###  Leaderboard

* View student rankings
* Track performance and achievements
* Encourage healthy competition and engagement

###  Performance Analysis

* Visualize student performance
* Analyze progress across different activities
* Identify areas for improvement

###  Skill Gap Analysis

* Track existing technical skills
* Identify skill gaps
* Support focused skill development

###  Role-Based Interfaces

The platform provides dedicated workflows for different users, including:

* **Students**
* **Organizers**
* **Judges**

Each role receives relevant functionality and dashboards based on their responsibilities.

##  Getting Started

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/sharma15isha/Milaap.git
```

Navigate to the project:

```bash
cd Milaap
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
